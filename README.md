# Tropical Paradise

A responsive island-experience website built with HTML, SCSS, and vanilla JavaScript.

## Run locally

Serve this folder with a local static server:

```sh
npx --yes http-server . -p 8000
```

Then visit `http://localhost:8000`.

## Features

- Responsive navigation and travel destination sections.
- Destination cards that reveal island details.
- SCSS source in `sass/` and the compiled stylesheet in `css/`.

The contact section is static; the project has no booking or contact backend.
